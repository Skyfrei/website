State estimation under Gaussian noise

2026-09-14 • 1 min read • 245 words

State estimation under Gaussian noise remains a foundational problem in signal processing and tracking systems. When the underlying dynamical process is linear, the discrete Kalman filter provides the minimum mean-square error (MMSE) estimator.

System Model

Consider a discrete-time linear dynamical system governed by the state equation:

xk=Fkxk−1+Bkuk+wkx_k = F_k x_{k-1} + B_k u_k + w_kxk​=Fk​xk−1​+Bk​uk​+wk​

and measurement equation:

zk=Hkxk+vkz_k = H_k x_k + v_kzk​=Hk​xk​+vk​

where the noise terms are zero-mean Gaussian white processes:

wk∼N(0,Qk),vk∼N(0,Rk)w_k \sim \mathcal{N}(0, Q_k), \quad v_k \sim \mathcal{N}(0, R_k)wk​∼N(0,Qk​),vk​∼N(0,Rk​)

Prediction and Update Steps

The algorithm operates as a recursive two-step predictor-corrector:

  1. A priori state estimate: x^k∣k−1=Fkx^k−1∣k−1+Bkuk\hat{x}_{k|k-1} = F_k \hat{x}_{k-1|k-1} + B_k u_kx^k∣k−1​=Fk​x^k−1∣k−1​+Bk​uk​

  2. A priori error covariance: Pk∣k−1=FkPk−1∣k−1FkT+QkP_{k|k-1} = F_k P_{k-1|k-1} F_k^T + Q_kPk∣k−1​=Fk​Pk−1∣k−1​FkT​+Qk​

  3. Optimal Kalman Gain: Kk=Pk∣k−1HkT(HkPk∣k−1HkT+Rk)−1K_k = P_{k|k-1} H_k^T (H_k P_{k|k-1} H_k^T + R_k)^{-1}Kk​=Pk∣k−1​HkT​(Hk​Pk∣k−1​HkT​+Rk​)−1

  4. A posteriori state estimate: x^k∣k=x^k∣k−1+Kk(zk−Hkx^k∣k−1)\hat{x}_{k|k} = \hat{x}_{k|k-1} + K_k (z_k - H_k \hat{x}_{k|k-1})x^k∣k​=x^k∣k−1​+Kk​(zk​−Hk​x^k∣k−1​)

  5. A posteriori error covariance update: Pk∣k=(I−KkHk)Pk∣k−1P_{k|k} = (I - K_k H_k) P_{k|k-1}Pk∣k​=(I−Kk​Hk​)Pk∣k−1​

Scalar Implementation

In the 1D case where F=1F = 1F=1 and H=1H = 1H=1, the matrix inverses collapse into simple scalar divisions:

struct Kalman1D {
    float x; // State estimate
    float p; // Estimate error variance
    float q; // Process noise covariance
    float r; // Measurement noise covariance

    float update(float measurement) {
        // Predict
        p += q;

        // Update
        float k = p / (p + r);
        x += k * (measurement - x);
        p *= (1.0f - k);

        return x;
    }
};
